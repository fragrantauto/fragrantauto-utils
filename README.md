# fragrantauto-utils

`fragrantauto-utils` is a high-performance Python toolkit designed for automated DEX route optimization and gas-efficient EVM transaction execution. Built for algorithmic traders and DeFi developers, it simplifies sub-second liquidity state queries, mempool monitoring, and MEV-resistant order submission across Ethereum-compatible networks.

## Features

- **Multi-DEX Path Finder**: Dynamically calculates optimal swap routes across Uniswap V3, Curve, and SushiSwap pools using local state caching.
